# UI-01 acceptance cases

These are planned tests for both apps. Their source fixtures are the existing app docks, current built-in behavior and the public-SDK Dockable Control Studio. Record the exact framework pin in each run. All cases are unrun.

| ID | Setup and action | Expected observable result |
|---|---|---|
| UI01-workspace | Enable a package with two panels and a preset. Open by Window menu and command palette. Tab with built-ins, resize, collapse the column, float, close and reopen. Repeat with an unrelated package using the same titles. | One dock tree. Active tab, focus, placement and open state belong to the correct instance. Each draws through the same shared framework mechanism as built-ins. A renamed label keeps the key. |
| UI01-platform | Choose InApp and PreferNative for two eligible groups. Add an ineligible tab to the second. Move and resize across two monitors with different scale. Remove one monitor, close/reopen and redock. Re-run with the runtime reporting unsupported positioning. | User preference, last valid normal geometry and dock-return location survive. The ineligible or unsupported group gets an attributed in-app float. With native support restored, PreferNative can return to a reachable OS viewport. InApp stays in the app. |
| UI01-a11y | Open a custom editor and an accessible fallback. Use keyboard and screen-reader action to activate a control. Change language, theme and scale. | Host identifies the plugin and viewport. The semantic name, role, value, enabled state and action belong to the focused node. No loss of keyboard navigation after reparent. Color, size and density use the framework rules. |
| UI01-pass | Force `request_discard` during a text commit and a slider release. In a native pane, submit a text field with a shortcut key and release its focus in that pass. | One semantic action for the received input, one document commit where applicable, and zero duplicate root shortcuts. No repeated pointer delta on rerun. |
| UI01-modal | A protected host modal opens in the pass of a staged plugin click and a ready reply. Include a popup in another viewport and a pointer capture on the plugin canvas. | Modal keyboard/pointer ownership applies before staged effects. Blocked captures, popup and IME end. No guest event or stale commit slips through from the blocked scope. |
| UI01-drop | Drop a file over a plugin's explicitly authorized zone and another over ordinary app chrome in a native window. Repeat after revoking the grant. | Exactly one recipient, selected with the real origin available. Plugin receives only the brokered handle with intended rights. Denial confers no path or implicit edit and no duplicate import. |
| UI01-edit | Open equivalent docs A and B whose layers share an ID. In the panel, begin an edit on A and switch to B. B references a different relative asset. Deliver the same reply twice and after receipt expiry, then race a revoke and a failed prepare. | If A remains a valid target, success is one labeled Undo, one damage and document revision and A's asset context. Switch never addresses B. Revocation and failed preparation produce zero document/historical/session side effects. |
| UI01-preview | Cancel an in-flight drag preview in a native/locked viewer. Publish the committed revision, then release the older preview result. | The old render cannot enter a visible cache or replace committed output. No Undo, leaked capture or stale preview after cancellation. |
| UI01-recovery | Freeze, kill and restart a worker with two tabs, a canvas lease, an active edit gesture and a plugin modal. Rebind a live gesture action and simulate late IPC. Inject device loss with retired leases. | Window and built-in inputs stay responsive. Plugin dialog closes, transient state and handles release, preview rolls back, active placement remains, and old epochs cannot update or commit. New worker mounts in place without old input. |
| UI01-save | Save open, hidden and native-floated instances in active and named workspaces. Disable/uninstall the package, reload, save, reinstall and reopen. Interrupt a save. Try the same with a downgraded app, and with reuse of an old ScriptUI number. | Unsupported and absent nodes round-trip as bounded inert entries, old bytes remain recoverable, no resurrection of a closed pane, no identity theft through reused numbers. |
| UI01-trust | Attempt a protected-slot replacement, cross-package surface mutation, focus stealing and direct, subresource and brokered network access in every advertised execution mode. Choose an eligible inspector replacement, then disable it. | Protected UI and resources remain unreachable. The approved replacement is attributed, switches back to default on disable and can be restored without loading the worker. |
| UI01-frame-cost | Alias of `CONF-cadence` (C gate); budget per conformance tolerance table. | |

Platform rows need macOS, Windows, X11, Wayland and web where the app has a UI build. Tests should separately report effective native support and the continued usability of the fallback. Headless tests exercise registration, workspace parsing, authority and history without claiming GUI outcomes.
