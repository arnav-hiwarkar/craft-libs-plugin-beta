# UI-02 acceptance cases

These scenarios specify outcomes to verify in both apps after UI-01 mounting and the content provider exist. They are unrun.

| ID | Fixture and action | Expected result |
|---|---|---|
| UI02-mixed | Dock a panel containing a native inspector, a graph and a preview image. Decorate a standard toggle. Resize, float, rescale across monitors and switch locale, RTL, density and contrast. | Composition uses the same clip and transform for pixels, hit regions and accessible bounds. One native action for each pointer, keyboard or screen-reader activation. Protected chrome stays host-owned. |
| UI02-update | Send a valid keyed move, a patch against the wrong revision, an oversized nested fallback and a full resync. Deliver an earlier asset decode after rebinding and revoke document access during a stalled patch. | The host publishes each admitted update atomically. Rejection retains the prior view. Stale replies cannot change the new binding. Focus and editing drafts persist only on continuous compatible nodes. No action occurs during replay or resync. Revoked pixels and accessible descriptions disappear before the next admitted frame. |
| UI02-invalidation | Change asset and negotiated GPU frame generations while a region is settled. Delete an offscreen focused row, reinsert the key with new actions and request activation using the old accessibility target. | Parent measurement and child paint/hit/accessibility state refresh together. Restore focus to an eligible stop. The obsolete focus transcript and old action cannot be replayed. |
| UI02-collections | Draw 10,000 variable-height rows with unloaded pages. Resize a column and turn on a new locale. Navigate to an unloaded keyed record by keyboard and assistive technology. Apply a reorder and release an old range response. | One current-generation page request per admitted range. The scroll anchor survives, pending actions cannot target an unknown row, and no whole-order paint or sizing scan occurs. Count extent probes, range requests, bytes, row paints and allocations. |
| UI02-canvas | Run a large node graph with active and inactive fallback branches. Pan, zoom and drag a connector while the worker stalls. Deliver geometry that expands past its reserved budget. | Host-local feedback, clipping and focus continue. Visual, hit and semantic state belong to a single published frame. The host rejects the expensive candidate without dropping the prior valid scene. CSS or native child windows cannot escape the host clip or modality. |
| UI02-device | Publish a leased GPU view. Lose its producer device, restore it, and deliver an old-generation frame. Repeat for a failed app presentation device, including an injected recovery-write error. Check color and alpha of a known fixture. | Producer loss while the app can still paint invokes the semantic fallback. The old frame is rejected. Actual window-device failure follows the app's recovery path and preserves unsaved recovery state if the recovery write fails. Reclaim or account for retired leases. |
| UI02-html | Use a verified isolated local HTML body. Reload its document while reply messages are queued. Exhaust ingress and crash it under a host modal. Repeat in an unsupported target. | The bridge refuses oversize input before unbounded queueing. Only the current browser generation may receive replies. On teardown, release focus, semantics and bridge together. The fallback supports the same actions. |
| UI02-cost | Alias of `CONF-cadence`; budget per conformance tolerance table. | |
