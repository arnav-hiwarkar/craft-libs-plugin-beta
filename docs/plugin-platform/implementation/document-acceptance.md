# Persistent extension document acceptance

These are planned app fixtures for the persistent object review (review record kept outside this repository). Run against both pinned apps and both legacy and new files. Compare the complete saved payload, typed model, undo history and render result where relevant.

| ID | Action | Expected outcome |
|---|---|---|
| DOC-object | Load a public SDK package contributing one built-in layer augmentation and one first-class procedural layer. Use normal add, reorder, hide, group, transform, select and inspect UI. | Both kinds use core placement and document IDs. One app-owned tree and history are visible. The new layer computes content through the negotiated processor. Ordinary mask/blend and bounding behavior matches a built-in with the same content. |
| DOC-transfer | Select a procedural scene with external references and a nested plugin-backed Smart Object. Duplicate as independent and linked, where the host supports linked content. Copy into a second document with colliding object IDs. | Stable plugin type/property keys survive. New instance and app object IDs are distinct. Declared references remap or become explicitly unresolved. Shared content changes only when linking was chosen. The entire operation is one Undo in the destination. |
| DOC-roundtrip | Save and reopen supported documents in EC JSON/XML and PC native ZIP. Uninstall the plugin, edit a built-in layer, autosave, restore and save again. Try newer/missing type, a failed migration and an older app. Repeat with Save Copy, incremental save and recovery files. | Opaque bytes, typed authored schema and embedded assets survive. No automatic code activation. Failed migrations leave original state and labels intact. An older writer can preserve the complete data or refuse that save, with a separately chosen compatible copy path. |
| DOC-assets | Load identical assets referenced across instances, snapshots and history. Delete one, undo while export reads an older snapshot, and simulate a stale link and corrupt embedded hash. Move just the portable project artifact to an independent profile. Interrupt a regular write and a recovery write before and after publication. Race a late old revision and inject a post-replace durability failure. | Retain data while any revision needs it. Dedup storage with explicit atomic publication and safe cleanup. No network or raw rights from a stored link. Old writes cannot win. A visible replace with unconfirmed durability is reported distinctly. Corruption fails safely and produces a bounded diagnostic. |
| DOC-missing | Edit a new effect or procedural layer and save a preview. Reopen with provider disabled, changed release digest, missing dependencies or render fault. Forge a stored bake with internally matching digest claims. Compare exact export and full-composite save at requested region, time, format and quality. | Preview or inert placeholder is visibly attributed. Ordinary reopening preserves the record. Exact export requires valid providers or a verified complete explicit bake for the matching coverage and never writes stale pixels as final. Changing one relevant dependency invalidates the bake's eligibility. Forged metadata is insufficient for exact reuse. The authored document can still be saved with the missing optional composite reported. |
| DOC-properties | Author typed nested values, an enum, units, color, vector path and object reference. Drive EC keyframes, typed interpolation and expression dependencies. Drive PC Smart Filter/adjustment bindings in normal Properties and undo. | Types and property IDs round trip. Stable control bindings follow remaps. EC evaluates in the documented time/units and PC advertises supported editing and animation honestly. A legacy number array cannot silently substitute for a structured property. |
| DOC-invalidate | Change a local asset, animated property or input filter. Reopen after plugin bytes change. Seek in reverse order. Add a same-time dependency cycle, a lawful finite previous-frame recurrence and a dynamic expression recursion. | Invalidate all and only safe affected extents/intervals. Provider digest changes invalidate reused filter stages. Cycles and budget errors report a bounded fault. Exact rendering never silently skips an unavailable stage. |
| DOC-legacy | Alias of `RET-*`; budget per conformance tolerance table. | |

Fixture source anchors are the native format and filter traces (review record kept outside this repository) and [legacy inventory](legacy-inventory.md). For large assets, record stored bytes, retained snapshot bytes, decompressed payload bytes, filter work, and both preview and final latencies.
