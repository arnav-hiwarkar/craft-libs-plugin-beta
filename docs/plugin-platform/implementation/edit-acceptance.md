# Input, commands and document edits acceptance

All tests are planned. Drive the same fixtures through the real UI, SDK and applicable headless entry points. Track document identity, revision and actual history effects in addition to pixels.

| ID | Case | Expected result |
|---|---|---|
| EDIT-capture | Use a gasket-shaped brush across PhotoCraft tiles and record an EffectCraft Puppet Pin move. Send pressure, tilt and modifiers at high rate. Drop one required sample batch before End. Inject a repeated pass and a DPI change. | Each physical sample enters one owner's ordered batch. The cursor and basic feedback remain local. Transforms and snapping match the intended viewport, with explicit cancellation for an incompatible basis. One final mutation and Undo per complete gesture. A missing sample cancels the affected gesture. |
| EDIT-cancel | Stall PhotoCraft's paint preparation after press, release then open a host modal before publication, and try another stroke. Revoke after End in a separate test. | The UI keeps painting. One input terminal. The pending edit expires independently of capture and cannot publish. Late effects and previews are rejected. |
| EDIT-overlay | Draw custom selection and manipulation overlays across split native views and stale contexts. Export at the same time. | Only the authorized viewport and live document see the overlay. Local hit priority preserves navigation and built-in protected controls. Export and committed pixels exclude pending preview surfaces. |
| EDIT-target | Open A and B with the same layer IDs, distinct relative assets and concurrent selection changes. Start an edit in A and change B and its Action state before publication. | Changed active selection never redirects the edit. Preparation uses A's path and captured context. Success publishes once on A, while failed and stale cases leave B, history capture, dirty state and journal untouched. |
| EDIT-editor | Record multi-pin keys through EffectCraft's ordinary tool slot. Scrub and select while the worker prepares. | Only documented dependencies gate the keyframe edit. Commit does not overwrite newer editor time, selected keys or active composition, and leaves one labeled Undo. |
| EDIT-atomic | Stage two canonical operations with the second failing. Save/autosave and observe events during preparation. Retry after outcome expiry. The kill and revoke cases are an alias of `T-crash-commit`; budget per conformance tolerance table. | No partial document, history, journal, analysis queue or notification appears. A spent ticket cannot execute a second time and returns `Expired` after receipt eviction. |
| EDIT-hook | Register a replacement and two wrappers plus a subscribed observer. Race reorder, veto, rewrite, deadline, revocation and a nested PhotoCraft Action with a playback substitution. Exercise EffectCraft deferred external-open effects with an inert sink. | Authorized projected arguments only. Deterministic provider choice and restoration, contributor grants checked before publication, protected operations remain host-owned, and async paint never waits. No causal loop or unauthorized local/remote leaf. |
| EDIT-events | Divide committed events and latest-value progress. Force observer overflow, request a resync, commit between snapshot and next poll, lose an acknowledgment and revoke while a delta is queued. | Snapshot and watermark form one cut. Resume without missed or duplicate committed deltas. Replay is deduplicated and no queued record is disclosed after revocation. An action receipt still reports the actual edit result even when its notifications were coalesced or overran. |
| EDIT-bulk | Query 10,000 layers and slices of million-point geometry, including a filter matching zero rows. Switch target composition, change timeline time, and revoke permission while serialization runs. | Frozen projection time/selection and scope until expiry. No per-element IPC or unbounded visit. No ready result delivered after revocation. Record visited items and bytes independently. |
| DOC-multi | Open documents A and B. A panel lists them with `doc.list`, mints a ticket for B with `doc.ticket` from a user click, and commits to both. Rename a layer in B between read and commit. Retry without a user chain. | Each document gets its own Undo and receipt. B's commit returns `Stale(ReadKey[])` with no Undo while A commits. A plugin chain alone cannot mint a ticket. `doc.list` shows only documents under a read grant. |
| RES-library | A package adds a brush, a gradient, a swatch, a LUT and a tool preset through the resource library operations. Uninstall it, then use the entries and replay a preset. | Typed entries appear in the native libraries with `Provenance(Chain)`. Replay runs under the author chain and opens the adopt sheet when the author is missing. Library writes have receipts and no document Undo. |
| INPUT-device | Pick a MIDI controller and a HID device in the host picker and bind them to parameters. Unplug, revoke and try an OSC address. | Events arrive only after the pick. Unplug and revoke end the stream with typed outcomes. OSC is refused as network. |
| CAPTURE-open | Pick a camera, a screen and a microphone in the host picker and feed a processor. Revoke mid-stream. | Frames arrive as read leases and audio as `AudioBlock`s. The Principal process never opens the device. Revoke closes the stream at once. |
