# Processor acceptance cases

Planned real-provider checks for RENDER-01/02. Use public SDK packages, the apps' normal render and export paths, and fixtures with known pixels or geometry. The eventual processor contract assigns exact types and limits. These tests have not run.

| ID | Fixture | Expected result |
|---|---|---|
| RND-format | Process linear HDR RGB, nonlinear/profiled RGB, grayscale, transparent HDR, Lab and separated CMYK or other advertised native modes. Use a 2×2 image with straight alpha zero, partial alpha, signed channels and a highlight greater than 1. | Identity preserves supported channels, alpha, profile and sample semantics. A conversion has an explicit descriptor and known reference result. Unsupported format pairs fail before guest execution. Zero alpha does not vector-divide or mutate untouched channels. |
| RND-tile | Filter a sharp diagonal with a separable 3×3 kernel and one-pixel halo. Request the same result as a full rectangle, odd-width tiles, bands, cropped display regions and export. Add two inputs, an offset mask, and negative-origin bounds. | Expected kernel samples at edges match the declared boundary rule. The stitched tiled and untiled outputs agree within the declared precision. Regions and offsets agree in canonical source coordinates. Halo or mask changes invalidate the affected downstream output. |
| RND-full | Use a global histogram pass and a global image generator. Request a small visible tile and a large final raster. | The declared full-frame or reduction requirement is charged and scheduled once for a common key, then its output can be sliced. A bounded quota failure is typed and never presents a preview as final. |
| RND-authority | Queue CPU calls under document A's revision, switch target to B, revoke and then release a late completion. Attempt buffer/window/format target mixups and retain the input across invocation expiry. Inspect newly exposed padding and revoke one admitted secondary input. | No cross-target access or stale cache admission. The output needed for compositing is checkable and immutable once published. Leases drain or remain charged until safe retirement. |
| RND-gpu | Declare a small shader and geometry scene that produces known color, depth and mesh bounds. Exercise binding mismatch, device loss, excessive dispatch work, wrong generation, incomplete producer and last-consumer fences, provider death after submit and large workloads. Inject app-device loss separately and deny the first recovery write. | Valid scheduled passes compose through the app's existing scheduler. Unvalidated workloads are rejected and device loss has explicit recovery. Geometry and preview resources remain coherent across producer generations. The guest receives no host device pointer. Unsaved state survives a failed recovery write and is retryable. |
| RND-cache | Warm PC's Smart Filter prefix and EC's effect chain, then swap package digest and input ICC profile. Disable the middle provider, undo, and export both exact and preview. | Keys reflect all actual dependencies and purpose. Incomplete cached stages remain incomplete. Undo restores appropriate authored state, without granting authority to execute a disabled release. A last-frame or mux failure leaves the old file hash unchanged. Sequence publication and Skip Existing report their exact coverage and provenance. |
| RND-scene-3d | Render a mesh, two lights, material controls and a camera at known transforms through the EC engine. Use the same author's own camera and projected raster surface in PC. | Supported scene capabilities provide typed depth and light inputs, geometry bounds and selection data. App domain mismatch returns explicit capability state. PC can use a projected raster and custom author view without a second app compositor. |
| RND-cost | Pair built-in and SDK effects at 1080p and 4K, one heavy EC composition, and a large high-bit-depth PhotoCraft image. Exercise cold compile, warm frame, tile reads and amortized upload. | Record workload, outputs, kernel execution, copy bytes at each boundary, in-flight memory, stalls and p50/p95/p99 latency. Verify no GPU fence wait in interactive paint. Label resource, backend and quality fallback separately. |

Use the matched-run method in [verification rules](../architecture/evidence-and-verification.md). Include negative provider cases. The [document contract](../contracts/document.md) defines completeness, bake eligibility and the distinction between editable save and exact publication.

## Existing integration fixtures

- EffectCraft `crates/host/tests/it/plugins.rs` and `crates/plugin/src/tests.rs` are legacy module and manifest fixtures. Use the latter's format and call behavior as evidence for an equivalent public processor. Native interactive target is the production layer effect path and composition viewer. Exact targets include full and direct YUV encoder routes.
- PhotoCraft `crates/plugins/tests/it/abi.rs` and `crates/automation/tests/it/smart_filter_stack_cache.rs` anchor band input and prefix reuse. Exercise layer effect enablement, visible damage, GPU RAII/resource residency and actual bytes through both layered and flat export. Preserve all admitted channel layouts and native unsupported outcomes.
- Historical shared `crates/ext-gpu/tests/gpu.rs` contains validation and device re-adoption cases. Reuse bounded fixtures for new isolated provider and asynchronous retirement tests. Check measured work before reporting backend advantage.
