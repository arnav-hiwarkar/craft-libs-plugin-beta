# Processor and render resource contract

Designed in [RENDER-01/02](../decisions/ADR-RENDER-01.md). Runtime and hardware gates remain pending. [Document provenance](document.md#typed-properties-and-render-provenance) · [Processor tests](../implementation/render-acceptance.md)

```text
ImageDesc = (extent, coordinate_space, origin, scale, mip, planes, color, alpha)
Plane = (channel_roles, sample_type, encoding, offset, row_stride, pixel_stride)
ProcessRequest = (ContributionRef, InstanceRef, ImmutableSnapshot, AuthorizedInputPorts,
                  OutputCoverage, Time, Purpose, ExecProfile, Seed, Budget)
ProcessPlan = (OutputExtent, InputFootprints, PartitionMode, Passes, OutputDescriptors)
PartitionMode = IndependentTiles | AnalyzeThenTiles | FullFrame
ProcessOutcome = Complete(Provenance, Resources) | Degraded(Reason[], Preview?) | Failed(Error)
Resource = CpuReadLease | FreshCpuOutput | TextureLease | BufferLease | GeometryLease
render.read(ticket|job, Target{layer|comp|stage_prefix}, TimePoint, Region, ImageDesc, Purpose) -> Lease + ReadKey
CacheKey = (ReleaseDigest, state digest, read-set tokens, ExecProfile, backend, format/colour/alpha,
            quality, time, region, seed, partition semantics)
text.fonts() -> FontRef[];  text.shape(font, str, features) -> GlyphRun{outlines, advances, clusters, engine_id, font_digest}
```

The app's render owner resolves immutable input parameters and ports before handing data to a `render` Store in the Principal process. The guest declares output extent and a plan for the actual request. Host validation checks all resolved document, source, time and resource dependencies. The scheduler composes accepted outputs in the app engine, using native masks, opacity, placement and blend rules. A producer cannot publish arbitrary app state or mutate input resources. Both ordinary app providers and plugin providers return typed completeness. Quality and provenance extend through compositing, conversion and the encoder.

## Guest reads

`render.read` is the guest-initiated read, used by jobs, scope panels, analysis and segmentation. It follows the same footprint, completeness and authority rules as host-invoked input ports. The returned `ReadKey` is the app dependency key (EC `input_key`, PC Smart Filter prefix) and joins the ticket's or job's read set, so publication compares its O(1) token ([invocation contract](operations.md#query-and-publication)). A read under a `preview_only` purpose cannot feed an exact output. Eyedropper sampling is host-side through `ParamAnnotation::Eyedropper` ([UI content contract](ui-content.md#parameter-annotations)); the guest never reads displayed pixels.

## Colors, coordinates and footprints

Describe finite, half-open pixel regions with a named native or transformed coordinate space, origin, scale and sampling grid. Input and output layouts describe native channels, byte order, plane splits, normalization, component widths and row and pixel strides. Validate every size/offset and trailing element with checked arithmetic. Alpha can be absent, associated or unassociated. Color channels carry profile or working-space digest, transfer, intent, black-point and reference-white information where relevant. Alpha coverage, depth, normals, label planes and spot plates stay outside RGB transfer functions. Use explicit per-stage precision and declared conversion, including upload, intermediates and encode. Refuse route combinations that cannot preserve required signed, high-depth, hidden-color or HDR data. Do not infer straight or premultiplied from channel count.

Expand each input independently using its transform, mip, extents, filter support, asymmetric halo and edge policy. Represent disjoint physical footprint spans, including a wrapped reference to a far-edge tile or a separately transformed mask. Bound spans and actual expanded work before allocation and key construction. Admit precision and actual resolved source, mip, mask, metadata and scene access jointly. When a mapping would expose an adjacent span outside scope, stage only authorized data. Recheck dependency grants at handoff, cache reuse and publication, including previews and bakes. Sparse native default pixels and truly unavailable input have different status. Derive tile invariance from absolute coordinates and seeded stable sampling. Global reduction jobs prepare a bounded shared summary with defined order. Full-frame or scene processors can compute a larger admitted footprint before returning a cropped output.

## Providers and leases

Run the portable CPU provider in `render` Stores in the Principal process. Native computation needs the reviewed offline execution proof. The host uses a typed batch resource path, with immutable input and fresh, exclusive output. Protected host mappings may avoid a transfer copy. Ordinary linear-memory marshal, sparse tile packing, halo and conversion can still copy. Sealed or copied results validate before cache admission. No live writer retains an alias after publication. Initialize defined output, every exposed plane and padding before transfer, including recycled pages.

The app device runs broker-owned bounded kernels on resident resources. The GPU provider controls encoding on a per-principal logical device in the shared GPU provider for general admitted GPU compute and drawing. Wasm, native and hybrid processors issue only typed graph requests. They receive no device handles. Require mode-specific offline engine and sink proof. Validate stage, bindings, formats, sampled features, attachment state, graph and supported device features jointly with the destination. Explicitly resolve multisample and depth/stencil to an agreed lossless transferred plane, or keep those attachments provider-private. Size and reserve runnable dependency slices, shader/compiler work, conversion and transfer staging, encoder/disk staging and allocation retirement before submit. Track aggregate and per-package quotas. Reserve interactive and exact-job credits with fair scheduling and avoid holding resources while waiting for work they depend on. The frontend uses no blocking completion wait.

The portable inter-device result path is readback to sealed CPU bytes and upload to an app-owned resource. Use external allocations only on a verified broker with writer exclusion, producer completion and last app consumer completion. Validation, import and app upload are consuming work. Validate `ReleaseDigest`, `DeviceGeneration` and import state, with driver/backend completion rather than guest assertions. Keep all intermediate and retired bytes charged until disallowed access is proven gone. Timeout cancels future work and prevents presentation. Device loss retires old-generation results. A provider crash or process exit cannot release allocations still in use by the driver or app. Faults quarantine the route. Preserve app recovery on shell-device loss, with retryable recovery on failed writes. Per-principal logical devices reduce direct resource sharing; a reset or adapter contention can still affect the app device and every principal.

## Composition and export

Typed geometry includes validated keyed paths, meshes, indices, materials and pass inputs/outputs, with app camera, lights, time, coordinate basis and conservative bounds. Native meshes and supported materials join the host scene. An arbitrary shader that must interleave with host transparency or occluders receives admitted scene dependencies for a whole scene batch through the GPU provider. A flattened color/depth plane alone fits explicitly compositable scopes. Use the host camera and depth conventions, transparency method, shutter samples and conservative bounds. Validate hit identity as well as positions and indices. Keep final matte ordering and protected overlay composition in the app. A raster host can accept projected imagery and custom views where native scene roles are unavailable.

The one `CacheKey` serves the render session cache, `job.unit` memos and `cache.put` slots. It covers admitted dependencies, source/grid/format and color, `ExecProfile`, quality, `ReleaseDigest` and state, time, seed, partition/analysis semantics and coverage; entries are dropped when the `PrincipalEpoch` or `DeviceGeneration` they were produced under ends. The durable bake identity is `BakeKey` ([document contract](document.md#records-and-participation)), built from verifiable content inputs rather than session hashes. Results preserve per-stage completeness from panel preview through prefix caches and final export. Exact mode accepts only complete coverage, verified provider provenance, a pinned `ExecProfile` and host-observed completion for every required chunk; the guest's success flag alone is insufficient. Backend retry within an exact job requires validated equivalence. Otherwise discard the unpublished attempt and prepare a fresh compatible route. Verify final status before external publication, including the direct YUV encode path. Stage artifacts privately through the final mux write. Verify destination identity and authorized overwrite policy at IO-01's publication sink. Clean up only staging artifacts owned by the job. A single file publishes atomically with the documented durability outcome. An exact sequence validates its complete required set before first publication. Each file replaces independently and records its own outcome after the barrier. If the user selects a per-artifact exact policy, report partial publication as such. Skip Existing either proves prior output matches provenance and scope or explicitly excludes skipped files from the current exact claim. Interactive use can display attributed last-good or degraded content while a provider recovers. Keep authored state and exact output independent of preview success.

## Text

TEXT-01 is a brokered host text service. `text.fonts()` lists installed fonts only, through the existing font catalog. `text.shape(font, str, features)` returns a `GlyphRun` with outlines, advances, clusters, `engine_id` and `font_digest`. It covers variable axes and colour glyphs. Glyph and byte caps are charged to WorkMeter. No font bytes reach the guest.

A document persists a font reference (family, style, axes and `font_digest`). When the font is missing, the host substitutes an installed font and attributes the substitution; the authored reference is kept. Font install or download, including `craft-font-store` and OS on-demand fonts, is a `Net` sink and is never admitted under a plugin chain ([runtime contract](runtime.md#network-denial)). Extrusion goes through the geometry route above. Tests: `TEXT-shape`, `TEXT-edit`, `TEXT-missing-font`.
