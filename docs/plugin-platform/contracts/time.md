# Time, timeline and audio contract

Designed in [RENDER-03/04](../decisions/ADR-RENDER-03.md), with runtime checks pending. The scene and [processor resource contract](render.md) apply to every sample. The app owns clocks and timeline editing.

## Time mapping and evaluation

Expose composition, layer, source and sample time explicitly. SDK time values have a signed integer coordinate and checked rational scale. Map through actual app time semantics, retaining the stage, resolved grid and versioned mapping in provenance. Use half-open valid intervals, floor containment in signed cells and exact boundary rounding in the app adapter. Distinguish a subframe view, a held source interval, frame interpolation, a reversed or non-monotonic time remap, nested protected regions and changed rates. Use source PTS for variable-rate inputs. PC's stored legacy f32 playback rate is normalized at the boundary; persistence preserves old documents. A still input has one identified sample and no implicit motion or audio track.

Plan per-port bounded earlier/later time, ROI, shutter positions, fields, masks and motion data. An upstream effect prefix is a separate node from its processed output. Authorize dynamic reads after resolving actual target, prefix, grid, footprint and projection. Meter mapping and expanded graph work before materialization. The host applies declared edge policies. Denied access, an authorized out-of-range sample, and unavailable decode are distinct outcomes. Missing input and authored transparent/silent padding are distinguishable. Preserve legacy EC ABI 2 neighbor-position and availability semantics during migration. No evaluation moves a live playhead.

A feedback group has a canonical rank independent of any non-monotonic source map. Resolve actual rank as canonical step and within-step dependency order. Combinational edges may read earlier stages in the same step. Feedback across a cycle must decrease the canonical step. Bound rank distance and expanded work toward the explicit base. Acyclic lookahead is permissible. A checkpoint and all derived output require a current authority closure. Resume only with verifiable host transition lineage from the base through the same input/properties, seed, algorithm, profile and resolved mapping. Version state and invalidation reach. Seek order, restart and Store scheduling do not change final state. State crosses requests only as host-held checkpoints keyed by `(instance, RecurrenceGroup | MixEpoch)`; the host may keep one warm Store per lane ([runtime contract](runtime.md#processes-and-turns)), and a cold Store resumes from the same checkpoint with identical output. Cache and invalidation use old and new mapping and dependency closures, including shutter, removed sidechains, nested remap and recurrence suffix. Widen to a bounded owning span when inverse mapping is uncertain. Cancel superseded preview and stale delivery. Reuse late work only for a current authority and exact matching cache key. Required preview and final outputs remain distinct.

## Editable roles

Timed source, procedural clip, transition, track and audio roles use app-native participation records. The app defines placement, occupied interval, source interval, trim, slip, split, retime, overlap, property/track ordering, history and fallback. A transition reads both app-resolved branches. Use the document transaction for explicit edits, including targeted inactive comps and layers. Split preserves the mapping and source epoch on each side. An explicit reset creates a fresh source epoch. Headless and export use the same committed snapshot resolver. PC captures per-frame content generation, eligible committed displayed edit and original/altered mode without updating live playback. Timed filter keys include these inputs, with still and visual roles available when a matching provider exists. PC's timed placement is separate from stored raster frames. Advertise frame/visual roles only after real edit and export support. Report unsupported track/audio roles per contribution. GIF and image-sequence exporters quantize cumulative time against the format grid and disclose deviations. Reuse canonical app lanes and selector. No second document timeline.

## Audio windows

A visual processor may declare an `AudioWindow(source, range, layout)` input. The host resolves the source's mixed or per-track samples over `range` around each requested time, in `layout`, and delivers them as an immutable read with the same authority and completeness rules as image inputs. The window adds an invalidation edge: an audio edit invalidates only the frames whose windows overlap the edited span. A host without an audio role reports `Unavailable(NoAudioRole)`. Test: `AUD-port`.

## Audio processing and transport

Expose immutable audio sample ranges with role/ordered channel layout, rate, signed sample index, start time, format, endianness, stride and planar/interleaved layout. Specify lookahead, algorithm latency, preroll, automation step offsets, tail and boundary policy. Use absolute positions for phase across sample conversion and partitioning. Resolve source direction and remap before DSP; retain the mix clock separately. Stateful DSP has canonical partition-independent rules, or a fixed versioned evaluation block and state schema. Its state crosses blocks only as a host-held checkpoint keyed by `(instance, MixEpoch)`, and a warm Store per lane may hold it between blocks. Distinguish valid audio, unavailable input and authored silence through mix, conversion and mux. Specify internal precision and range separately from PCM/encoded output clipping, dithering, priming and tail. Match export duration and device presentation against the corresponding video time.

Use one async transport lifecycle for playback and latest-only scrub. Preserve the existing scrub fade. Move browser evaluation off the UI pump. A failed or superseded device start reaps the feeder and all acquired resources even if no callback ran. Run general DSP and IO outside device callbacks. The feeder prepares admitted graphs or blocks under bounded lookahead and quota. Use a verified preallocated delivery queue. Publish readiness after device and graph configuration, preallocation and bounded prefill, only when the stream has started and completed its first valid handoff. The callback copies, applies bounded host conversion and meters, and fills missing output according to the selected local policy. Web worklet parity requires the same bounded preallocated queue without callback messages. For a target without verified real-time audio, report its absence and use the host visual clock where supported. It allocates no buffers, waits for no locks, accesses no broker or Principal process, and runs no guest code. Stop, seek, restart, rate and edit retire epochs without UI-thread joins or readiness waits. A bounded control request carries the new epoch independently of ring capacity. The callback owns cutover at the next unconsumed boundary and acknowledges stream, epoch, device boundary and next content coordinate. Explicitly retire a lost device clock and handle suspended-device cutover. Wait for the final audible span before natural stop. Keep device frame count, handed-off content, scheduled fallback and actual underrun separate. Correct hardware position for latency against bounded span history. A deliberate scheduled bypass/silence advances content, while device starvation holds the content position. Preserve already submitted spans until audible. Reject late outputs for expired epochs or replaced spans, including invalid checkpoints. Revoke before admitting additional blocks; already handed-to-device samples may still sound.

Host selects short prebuffer, authorized bypass with bounded crossfade, or silence for affected playback branch. Unaffected tracks continue. Grade degraded audio reports independently of content export. Select exact track presence from authored participation in the requested span. Carry typed decode failures through conform caches and AAC, Opus and standalone PCM. Offline exact mix uses no device, carries ExactStage<AudioBlock> and consumes typed ranges and requires all timeline/branch/encode coverage. Fail privately before publication if any exact source, effect, program span or mux write fails.
